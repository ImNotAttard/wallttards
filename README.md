# Montañas — wallpapers

Sitio estático para explorar los wallpapers de montaña de [dharmx/walls](https://github.com/dharmx/walls/tree/main/mountain). No necesita instalación ni compilación: los nombres y las imágenes se consultan directamente desde GitHub.

## Publicar en GitHub Pages

1. Subí `index.html` y este `README.md` a la raíz de un repositorio de GitHub.
2. Abrí **Settings → Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**, seleccioná `main` y la carpeta `/ (root)`.
4. Guardá. GitHub Pages publicará el sitio en unos minutos.

La página consulta la api pública de github y carga imágenes desde el repositorio original; necesita conexión. El selector incluye macos, windows, gnome, kde plasma, xfce, hyprland, sway (wayland) e i3. El wallpaper elegido se previsualiza en escritorio y móvil. El enlace de descarga abre el archivo original de dharmx/walls.
